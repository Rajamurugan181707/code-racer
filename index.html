Lines that match the track's program pass instantly. Any other line is compiled and run for real with Python 3.13, gcc 13.2 or OpenJDK 22 on the free Wandbox service (wandbox.org), which can take a few seconds. If Wandbox can't be reached, the game falls back to its built-in checker. Sound effects are made in your browser; turn them off with the Sound button. Progress, best scores and ghost runs are saved only in this browser.
